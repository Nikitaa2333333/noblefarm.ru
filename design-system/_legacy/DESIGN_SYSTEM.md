# 🌲 Дизайн-система «Благородный Север» (Noble Sever)

> **Статус**: Действующая официальная редакция.
> **Направление**: Премиальное фермерское оленеводство, экотуризм, велнес.
> **Философия стиля**: Строгий геометрический скандинавский минимализм. Чистота линий, обилие воздуха, естественные природные контрасты и редкие изящные акценты.

Этот документ является главным ориентиром для разработки и поддержки всех страниц веб-сайта. Он фиксирует правила использования геометрии, цветов, шрифтов и анимаций для поддержания целостного премиального облика бренда.

---

## 📐 1. Главные правила геометрии (Скругления и углы)

Главный экран сайта является эталоном стиля. Вся геометрия строится на трех строгих правилах:

### 1.1. Строгая базовая геометрия (`rounded-none`)
Все контентные и декоративные блоки, карточки, фотографии, секции, фоновые плиты и заглушки выполняются с **абсолютно прямыми углами (90 градусов)**:
*   Карточки оленей (Генетика) и модели дохода (Отрасль).
*   Превью новостей, карточки публикаций СМИ, блоки экскурсий.
*   Все фотографии в сетках и галереях.
*   Зеленые и светлые секционные фоновые блоки (например, «Почему генетика имеет значение», «Наш подход»).
*   *CSS класс*: `rounded-none` / `border-radius: 0px;`

### 1.2. Деликатные элементы управления (`rounded-[6px]`)
Кликабельные элементы, кнопки, мелкие теги, поля ввода и контроллеры имеют очень строгое, деликатное закругление **`rounded-[6px]`** (или `rounded-[8px]` в редких случаях). Это убирает лишнюю остроту с интерактивных зон, не превращая их в бесформенные овалы:
*   Кнопки `.btn-primary` (основные) и `.btn-outline` (контурные).
*   Кнопки категорийных фильтров новостей.
*   Переключатели подвкладок (Sub-tabs) и рамки вкладок.
*   Теги родословных и статусов.
*   Кнопки в Navbar и Footer.
*   *CSS класс*: `rounded-[6px]` / `border-radius: 6px;`

### 1.3. Фирменный асимметричный акцент («Один скошенный угол»)
Для подчеркивания премиальности и изящества используется уникальный росчерк — **прямоугольный блок, у которого закруглен только один нижний правый угол**:
*   Применяется **исключительно** для:
    *   Главных карточек направлений на домашней странице (Directions).
    *   Главных промо-баннеров (Hero) на внутренних страницах.
*   *CSS классы*:
    *   Десктоп: `rounded-none rounded-br-[80px]`
    *   Мобильный: `rounded-none rounded-br-[40px]`

## 🎨 2. Цветовая палитра (Color Palette)

Мы используем глубокую, насыщенную палитру «хвойного леса и северного золота». **Категорически запрещено использование полупрозрачного серого или размытого текста.** Все цвета должны быть плотными, глубокими и обладать высокой контрастностью (минимальный коэффициент 4.5:1).

| Роль | Цвет (HEX) | CSS / Tailwind Переменная | Описание |

| **Primary (Основной)** | `#1B4344` | `bg-primary`, `text-primary` | Глубокий благородный хвойный / лесной зеленый. |

## ✍️ 3. Типографика (Typography)

Типографика отражает баланс серьезности сельского хозяйства и эстетики премиального отдыха.

*   **Заголовки (Headings)**: Премиальный антиквенный шрифт **Century Schoolbook** (Serif) с засечками. Придает тексту благородство и историческую глубину.
*   **Основной текст (Body)**: Современный, технологичный геометрический гротеск **Manrope** (Sans-serif). Обеспечивает идеальную читаемость.
*   **Иерархия заголовков в карточках (Card Headings)**: Заголовки плашек и карточек никогда не должны выглядеть мелкими на фоне плотного (`font-semibold`) наборного текста. Для выразительности, весомости и сохранения премиальной иерархии:
    *   Заголовки карточек и характеристик оформляются крупным размером **`text-xl`** (20px) или **`text-2xl`** (24px).
    *   Используется исключительно плотное жирное начертание **`font-bold`** (Bold) и гарнитура **`font-serif`** (с засечками). Это делает заголовки заметными, контрастными и эстетически доминантными над описанием.
*   **Строгое правило регистра**: **НИКАКОГО КАПСА (UPPERCASE) во второстепенных заголовках и кнопках.** Весь текст пишется в естественном регистре предложений (Natural Case). Капс разрушает изящество макета.

## ⚙️ 4. Интерактивные компоненты и классы

### 4.1. Кнопки (Buttons)

Все кнопки описаны в файле `src/index.css` и имеют скругление `6px`:

```css
/* Основная кнопка (Золотая заливка, темный текст) */
.btn-primary {
  @apply px-9 py-4 bg-accent text-secondary text-base font-semibold rounded-[6px] hover:bg-primary hover:text-text-light hover:-translate-y-0.5 transition-all duration-300 shadow-md cursor-pointer;
}

/* Контурная темная кнопка */
.btn-outline-dark {
  @apply px-7 py-3.5 border border-primary text-primary text-base font-semibold rounded-[6px] hover:border-accent hover:text-accent hover:-translate-y-0.5 transition-all duration-300 cursor-pointer;
}

/* Контурная светлая кнопка (для темных фонов) */
.btn-outline-light {
  @apply px-7 py-3.5 border border-border-dark text-text-light text-base font-semibold rounded-[6px] hover:border-accent hover:text-accent hover:-translate-y-0.5 transition-all duration-300 cursor-pointer;
}
```

### 4.2. Карточки (Cards)

Все контентные карточки строго прямоугольные:

```css
/* Интерактивная карточка (Смена цветов при наведении) */
.card-interactive {
  @apply bg-bg-card text-text-dark rounded-none p-8 border border-border-light hover:bg-primary hover:text-text-light hover:border-primary transition-all duration-500 hover:-translate-y-1 hover:shadow-2xl cursor-pointer;
}

/* Статическая карточка */
.card-static {
  @apply bg-bg-card border border-border-light rounded-none p-7 hover:border-primary hover:shadow-md transition-all duration-300;
}
```

## 💫 5. Анимации и переходы (Transitions)

Для создания премиального ощущения от использования сайта (UX) все интерактивные переходы должны быть плавными и лаконичными:

1.  **Плавная смена экранов**:
    *   Применяется Framer Motion: `initial={{ opacity: 0 }}` -> `animate={{ opacity: 1 }}` с длительностью `0.4s` - `0.5s`.
2.  **Минималистичное переключение подвкладок (Sub-tabs)**:
    *   Категорический отказ от сложных, прыгающих или пружинных анимаций скольжения (`layoutId`), которые перегружают интерфейс и создают «тяжесть».
    *   Применяется легкое, чистое проявление активного фона через изменение прозрачности: `initial={{ opacity: 0 }}` -> `animate={{ opacity: 1 }}` с короткой длительностью **`0.15s`**. Это делает отклик мгновенным, легким и технологичным.
3.  **Микро-взаимодействия (Hover эффекты)**:
    *   Любое наведение на интерактивный элемент (ссылка, карточка, кнопка) сопровождается переходом не менее `300ms` (`transition-all duration-300`). Мгновенные скачки цвета запрещены.

## 🚫 6. Антипаттерны (Чего делать нельзя)

*   ❌ Использовать сложные, прыгающие, пружинные или тяжелые деформационные анимации для переключателей и плашек.
*   ❌ Использовать жесткие, выраженные или объемные тени — тени должны быть либо полностью отключены (`shadow-none`), либо быть практически невидимыми (`shadow-xs` с низкой опасити), уступая место тонким аккуратным рамкам `border-border-light`.
*   ❌ Использовать `rounded-full` для обычных кнопок или плашек (превращает премиум-минимализм в «детский интерфейс»).
*   ❌ Использовать чистый черный цвет (`#000000`) — только темно-зеленый графит `#071717`.
*   ❌ Допускать полупрозрачный серый текст под заголовками (разрушает строгость и снижает контрастность).
*   ❌ Применять трансформацию текста `uppercase` для обычных кнопок и меню.
